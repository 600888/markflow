示例：技术选型文档

一、整体架构

本项目采用 React + FastAPI + Tauri 三层架构，Tauri 负责桌面外壳和进程管理，Python FastAPI 承载 Pandoc 转换逻辑，React 负责 UI 渲染。

二、技术栈

后端使用 FastAPI + Pandoc，转换引擎通过 pypandoc 库调用 Pandoc 命令行工具，支持 DOCX / PDF / HTML / EPUB 等多种格式输出。

三、模版系统

内置学术论文、报告、简洁三种模版，通过 --reference-doc 机制控制字体、行距、缩进等样式。支持用户自定义模版上传。
